# ThreatLens-ML
ThreatLens ML es una herramienta ligera de detección de amenazas basada en Machine Learning. Detecta malware en binarios, anomalías en tráfico de red, phishing en URLs, comportamientos sospechosos en logs y calcula puntuaciones de riesgo para IoCs. Todo en Node.js, sin Docker, 100% open source.
